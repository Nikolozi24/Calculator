# Calculator

# How to Run Code?
here is how.

in linux make sure you have a python.
check with command 
```
python3 --version

```
if you have that  in order to run command u need to install library 
with command:

```
sudo apt-get update
sudo apt-get install python3-tk
```

and hit enter. 

run the code.

in directory run code 
```
python3 Main.py

```
